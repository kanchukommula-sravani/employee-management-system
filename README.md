# Employee Management System

A simple, interactive Employee Management System built using HTML, CSS, and JavaScript. This project allows users to manage employee records through a form and stores the data in the browser using Local Storage.

## Features

- Add new employee records
- View employee details in a table
- Edit existing employee information
- Delete employee records with confirmation
- Validate form fields before adding or updating records
- Prevent duplicate employee IDs
- Store records using browser Local Storage so data persists after refreshing the page

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Form handling, CRUD operations, and validation
- **Local Storage** – Client-side data persistence

## Employee Details

Each employee record contains:

- Employee ID
- Name
- Role
- Salary

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add, edit, or delete employee records.
